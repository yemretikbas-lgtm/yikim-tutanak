YIKIM TUTANAK UYGULAMASI v1.0

- Rize ilçeleri butonla seçilir.
- Köy / Mahalle butonla seçilir.
- Yerleşim listesi mevcut Rize saha uygulamasındaki veriden alınmıştır.
- Kişi adları elle eklenir; birden fazla kişi desteklenir.
- Tek kişi: vatandaşımıza / konutun
- Birden fazla kişi: vatandaşlarımıza / konutların
- Yıkım tarihi elle girilir.
- Telefon kamerasından fotoğraf alınır; JPEG'e dönüştürülüp sıkıştırılır.
- Word çıktısında 1. sayfa tutanak ve imza komisyonu, 2. sayfa fotoğraftır.
- Word dosya adı kişi ad(lar)ından oluşturulur.
- Uygulama GitHub Pages altında HTTPS ile PWA/offline çalışır.
